Refactored code
The following changes are drop-in replacements for the affected parts of the class. They preserve the existing structure and avoid an unnecessary redesign.
1. Refactor findBetterPatternMatch()
Make the matching result immutable and create a new result only when a better match is found.

private static RuleMatchForImport findBetterPatternMatch(
        String importPath, String group, Pattern regExp,
        RuleMatchForImport currentBestMatch) {

    RuleMatchForImport bestMatch = currentBestMatch;
    final Matcher matcher = regExp.matcher(importPath);

    while (matcher.find()) {
        final int matchStart = matcher.start();
        final int length = matcher.end() - matchStart;

        if (length > bestMatch.matchLength
                || (length == bestMatch.matchLength
                && matchStart < bestMatch.matchPosition)) {
            bestMatch = new RuleMatchForImport(group, length, matchStart);
        }
    }

    return bestMatch;
}



2. Refactor RuleMatchForImport
Make all fields final. This ensures that a match result cannot be accidentally modified after construction.

private static final class RuleMatchForImport {

    /** Position of matching string for current best match. */
    private final int matchPosition;

    /** Length of matching string for current best match. */
    private final int matchLength;

    /** Import group for current best match. */
    private final String group;

    private RuleMatchForImport(String group, int length, int position) {
        this.group = group;
        this.matchLength = length;
        this.matchPosition = position;
    }
}



3. Refactor hasAnyImportInCurrentGroup()
Replace the explicit result variable and break with an early return.

private boolean hasAnyImportInCurrentGroup(String currentGroup) {
    for (ImportDetails currentImport : importToGroupList) {
        if (currentGroup.equals(currentImport.getImportGroup())) {
            return true;
        }
    }

    return false;
}



Summary
These changes improve immutability, readability, and maintainability without introducing new classes or changing the overall design.
One important consideration: the original findBetterPatternMatch() updates the best match based on both match length and position. The refactored version preserves that selection logic.
